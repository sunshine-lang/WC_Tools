<!-- TITLE: 02 · 集卡名称 -->
<!-- CATEGORY: 集卡名称 -->
<!-- OUTPUT: 02_集卡名称.md -->

<!-- FOCUS -->
本场景处理集卡套组名称及套内卡片名称。先理解整套主题，再给每张卡片选择自然、简短、易辨认的德语名称；兼顾画面对应、名称差异和文字趣味。不处理分类为活动 UI 的卡册标题、装饰物名称或角色对白。

<!-- TASK -->
在本次 ready 文件中，按用户指定范围处理 `分类 = 集卡名称` 的记录，将 `game_text_en` 翻译或审校为 `game_text_de`。使用共用规则规定的任务模式，不因已有德语就自动切到审校，也不因某个目标为空就擅自扩大补译范围。套数、卡数、长度、图片有无均读取实际材料；不要求拆出试译表或新增交接附表。

<!-- RULES -->
1. **按真实套组阅读。** 结合完整 Key、Context 和实际内容识别活动及套组。以 `Ahalloween_set2_name` 为例，它通常是套名，`Ahalloween_set2_1_name` 等是套内卡名；其他活动的 `set2` 不能混入这一套。先阅读当前提供的套名及相关卡名，再处理获准修改的记录；缺少成员不补造，不假定每套固定有十条。卡片序号不自动表示合成等级，不能照搬棋子升级规则。
2. **套名与卡名承担不同作用。** 套名概括共同主题，卡名体现本卡的对象、动作、氛围或趣味。名称通常简短，但不强制全部改成名词短语，也不把套名、季节或节日词重复塞进每张卡。遵守源文标点及客户格式，不因“名称一般不加标点”删除原有感叹号或问号。
3. **用可确认的图片辅助命名。** 优先查看 ready 中实际可读取的内嵌图片或随附图片，结合客户连续色块区间、图片位置及 Key 系列确认对应关系；单卡图与整套参考图的证据范围要区分。不能全表按同色合组，不能把一张图当作整套每张卡的画面，也不强制要求另有图片映射 CSV 才能处理。图片不可读取、缺失或对应不明时如实说明；源文含义明确的可先给保守译名，只有关键判断依赖图片的行才列为待确认，不一律给每套报错。
4. **允许意译，但不创造对象。** 根据英文、整套主题和已确认画面选择自然的名称，不必逐词对应。调整修饰语、词序或表达方式时，保留本卡对象和区分其他卡片的关键含义；不添加没有依据的颜色、材质、数量、制作方式或功能。图文存在实质冲突时说明证据和候选方向，不默认图片或英文能消除所有冲突，也不把局部客户许可推广到整批。
5. **一致性不等于所有词一律替换。** 同一对象、同一词义及已批准的系列名称保持一致；不同画面或含义的卡片要能区分。不能把不同名称都简化成一个泛称，也不为避免重名而编造区别。相同源文或相同对象的重复名称不自动判错。普通物品词、固定专名和文化表达可有不同处理；不能规定同套所有 `Pumpkin` 都必须保留英文或都机械替换成一个德语词。
6. **创意与文化词按证据处理。** 先判断是谐音、头韵、固定表达还是普通描述，再尝试自然的德语趣味表达。原英语发音不必复制，不能为押韵丢对象或改成另一文化节日。品种名、人物名、口味名等先查本行术语及已提供的客户资料；不因英文首字母大写就全部保留英文，也不默认把所有名字德语化。无明确依据的候选不要标成客户已确认译法；文字趣味确有损失时简短说明，不把所有头韵变化都视为翻译失败。
7. **术语与现有译名要核对含义。** 词义相符时使用本行 `生效术语` 的指定德语形式，允许必要语法变化；人名也以客户指定译名为准，不强制照抄英文拼写。已有德语不自动成为金标，TM 中的同名词也需核对对象与活动。A 模式发现同套已有译名与新译冲突时，保留范围外原值并说明；B/C 模式只在获准范围内修正，不静默改动其他卡片或场景。
8. **逐行检查长度并回看整套。** 按实际 `limit` 和明确适用的客户上限处理，不把历史批次的 24 写成永久规则；客户的棋子 28 字符限制也不自动适用于集卡。空 limit 按共用规则保持简洁，不自行填数。超长时先压缩冗余表达、选更自然紧凑的用词，不能截断固定名称、丢失区分含义或自创缩写。完成候选后回看同套名称：是否一致、是否误撞名、是否仍能对应画面、是否符合各自限制。最终输出保持原表行序，不按阅读顺序重排。

<!-- EXAMPLES -->
| 输入或情况 | 应采用的判断 |
| --- | --- |
| `Ahalloween_set2_name` 与另一活动的 `_set2_name` | 套号相同不足以认定同组，必须连同活动前缀和实际语境区分。 |
| 同套的 `Leafy Memories` 与 `Leafy Impressions` | 保留共同的叶片主题，结合语境和图片辨认两者差别；不能为了统一都译成同一个“秋日回忆”，也不只凭 Impressions 就认定画面是拓印。 |
| `Paper Pumpkins`，没有可确认的单卡图 | 可以依据英文保留纸制南瓜的含义，不能自行确定是折纸灯笼、剪纸或某种发光装饰。 |
| `Pumpkin Spice Sip` | 留意香料风味和饮用含义，结合已提供资料处理文化表达；不能只因套里另有南瓜就一律直译成南瓜实体，也不自行指定为拿铁或增加配料。 |
| `Unnerved Nik`，本行术语为 `Nik (Nick)` 且词义相符 | 使用指定的 `Nick`，同时表达人物不安的状态；不把“人名不翻译”误解为必须保留 `Nik`。 |
| `Crystal Ball`，本行术语为 `crystal ball (Kristallkugel)` 且对象相符 | 采用给定术语，不为同套的头韵另造同义名称。 |
| 两张含义不同的卡片候选译名相同 | 回看源文及对应图片，恢复有依据的区别；若原文和对象本就相同则保留一致，不随意补“红色”“高级”等修饰词。 |
