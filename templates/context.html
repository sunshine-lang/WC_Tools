功能说明

按活动、套组和对白 Key，关联当前上传文件中的英文原文，并新增 Context 列。

使用规则
  • 上传第一步下载的分类结果（.xlsx），原有内容与顺序保留。
  • 缺少完整 Key 或无法可靠分段时，标记待确认，不按角色名或行号猜测。
  • Context 仅保留关联原文；状态、来源和检查提示在预览中查看。无法关联的单元格留空。
  • 本步不需要 TMX。参考范围限定为 WC-UI 目录，禁止使用 done 结尾的材料和旧版工具缓存。
查看关联规则与可选补充
  • 活动 UI：优先关联同一用途的标题与说明；活动介绍配玩法引导，收藏页和成功／失败状态分别关联。
  • 集卡：按套组编号关联同组卡册名和卡名。
  • 装饰物与对白：依据完整 Key 关联，句序按数字排列；跨段线索只取当前文件内可验证的原文。

只从下列本目录现有文件中选择。文件缺少的 Key、气泡或图片会明确提示，不从其他目录补齐。

本目录材料不作为待译答案。德语列和其他语种规则不会进入上下文。
